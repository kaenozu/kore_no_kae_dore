# 実機確認チェックリスト

## 基本セットアップ
- [ ] `flutter build apk --debug` が成功する
- [ ] APKが実機にインストールできる（adb install / 直接ダウンロード）
- [ ] アプリアイコンが表示される
- [ ] アプリアイコン下に「これの替えどれ？」と表示される

## カメラ起動
- [ ] 「電球」カードをタップ → 撮影ガイド画面に遷移する
- [ ] ステップ表示（1/3 電球全体を撮影）が正しい
- [ ] AI判定ステータスが表示される
- [ ] 「撮影する」ボタンをタップ → カメラが起動する

## ギャラリー選択
- [ ] 「画像を選ぶ」ボタンをタップ → ギャラリーが開く
- [ ] 画像を選択 → 判定中 → 次のステップへ進む

## Mock判定フロー（APIキーなし）
- [ ] AI判定ステータスが「AI判定: Mock」になる
- [ ] 「AI判定: Mock」の場合、プライバシー注記に「画像は送信されません」と出る
- [ ] 写真撮影 → Mock判定 → full_view判定 → 次のステップへ進む
- [ ] 全3回の撮影後、器具確認画面へ進む
- [ ] 確認完了 → 手動確認へ進む

## 手動フォールバックフロー
- [ ] 「写真ではうまく撮れない → 手動で確認」をタップ
- [ ] 手動確認画面に遷移する
- [ ] 全項目を選択して「確認して次へ」 → 購入結果画面へ進む
- [ ] 結果に「手動入力に基づく候補」「写真確認が不足しています」の注意が表示される

## 復元ダイアログ
- [ ] セッション進行中にアプリを終了 → 再起動 → 復元ダイアログが表示される
- [ ] 「続きから」 → 前回の続きから再開できる
- [ ] 「新しく始める」 → 新規セッションが開始される

## 履歴保存
- [ ] 購入結果画面 → ホームに戻る → 「履歴」アイコンをタップ
- [ ] 履歴一覧に結果が表示される
- [ ] タイトル・日時・信頼度・検索ワードが表示される

## アプリ再起動後の復元
- [ ] アプリを完全に終了 → 再起動
- [ ] 復元ダイアログが表示される
- [ ] 「続きから」 → 前回の続きから再開できる

## AIバックエンド（未提供）
- [ ] 認証済みバックエンドを構成してから別途受入確認する

## ネットワークなし
- [ ] 機内モードで起動
- [ ] Mock判定で動作し、画像を外部送信しない
- [ ] Mock判定で正常にフローを完了できる

## 権限拒否時
- [ ] カメラ権限を拒否 → エラーメッセージが表示される
- [ ] ギャラリー権限を拒否 → エラーメッセージが表示される

## エラーハンドリング
- [ ] 分類器が例外をthrow → ユーザー向けメッセージがSnackBarに表示される
- [ ] 例外詳細（StackTrace等）がUIに直接表示されない
